# Couponz 대본 검토 절차 초안

이 파일은 저장소용 재사용 절차 초안이다. 개인 스킬 설치나 실제 영상 제작 완료를 뜻하지 않는다.

1. 최신 사용자 범위를 먼저 확인한다. 현재 합의는 대본까지이며 편집효과·속도·자막스타일·전환·CTA 시각표현을 정하지 않는다.
2. 공식 링크와 예정 사용일을 받아 원문을 직접 읽는다. 앱 전용이면 필요한 화면녹화의 경로·조건 상태만 요청한다. 사용자에게 좌표·시간표·JSON을 작성시키지 않는다. 기존 자료를 먼저 확인한다.
3. 대상·기간·최소금액·상한·제외·중복·필수비용·세금과 각 금액의 증거를 연결한다. 모르는 값은 null로 남긴다. 포스터·예상 화면·미지급 청구서·부분 영수증을 실제 지급 완료로 승격하지 않는다.
4. 주 질문에 맞게 단일/비교/절차/모음/장바구니 중 하나를 선택하고 이유를 기록한다. 질문·대상·기간형 도입을 별도 본문 형식으로 추가하지 않는다. 모든 영상에 한 고정 순서를 강제하지 않는다.
5. 비교는 같은 구성·상품 종류·수량·자격·세금·필수비용을 확인한다. 모음의 독립 혜택은 합산하지 않는다. 장바구니 즉시 결제와 조건부 미래 보상을 분리한다. 실제 납부·지급은 그 증거가 있을 때만 말한다.
6. 제작 담당자가 주장표를 작성한 뒤 `python -m couponz validate ...`와 `draft ... --out 새경로`를 실행한다. 미확인은 임시검토 문장으로 표시하고 최종 주장을 보류한다. CLI가 원문을 수집·검증했다고 말하지 않는다.
7. 한국어 문장·숫자·대상·조건을 사람이 검토한다. CTA·판단·조건 앞배치는 필요에 따른 추천이며 관측 사실과 구분한다. 레퍼런스 목적표집을 조회수 보장·인과효과로 바꾸지 않는다.
8. 수정은 새 파일에 남긴다. 실제 구현되지 않은 완전한 버전·복원·음성 QA·렌더를 완료로 표시하지 않는다. 대본 승인과 영상 편집 합의는 별개로 기록한다.

입력 계약·실행 명령은 `README.md`, `docs/usage.md`, 가상 사례는 `fixtures/`를 참고한다. 사용자 영상·음성·개인정보·키·분석 원문을 공개 저장소에 추가하지 않는다. 원격 게시·공유변경·계정생성은 이 절차의 실행 기능이 아니다.
