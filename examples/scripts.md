# 다섯 가상 대본 검토 예시

아래는 synthetic 시험 입력의 실제 엔진 출력입니다. 현재 행사나 사용자 승인 대본이 아닙니다. 시간·효과·자막스타일·화면 전환은 정하지 않았습니다.

## A · 단일 혜택 안내 · supported

- 역할 `benefit`: 가상 커피 혜택. 앱 회원은 커피 한 잔을 3,000원에 주문할 수 있습니다.

- 역할 `conditions`: 대상은 가상 앱 회원이고, 이용 채널은 가상 앱 주문입니다. 기간은 2026년 10월 1일부터 2026년 10월 31일까지입니다. 중복 사용 조건은 다음과 같습니다: 다른 쿠폰 중복 불가. 표시 가격은 세금 포함입니다.

- 역할 `cta`: 이용 전에 공식 안내에서 적용 조건을 확인하세요.

## B · 가격·구성 비교 · supported

- 역할 `baseline`: 버거와 음료를 따로 주문, 필수비용 포함 예상 금액 9,900원. 버거 7,900원과 음료 2,000원을 합친 구성입니다.

- 역할 `alternative`: 9,900원 세트, 필수비용 포함 예상 금액 9,900원. 같은 버거 1개와 음료 1개가 들어 있는 9,900원 세트입니다.

- 역할 `difference`: 양쪽 모두 9,900원으로 금액 차이는 없습니다. 구성을 보고 선택하세요.

- 역할 `conditions`: 두 구성의 공통 조건입니다. 대상은 가상 앱 회원이고, 이용 채널은 가상 앱 주문입니다. 기간은 2026년 10월 1일부터 2026년 10월 31일까지입니다. 중복 사용 조건은 다음과 같습니다: 다른 쿠폰 중복 불가. 표시 가격은 세금 포함입니다.

## C · 사용 절차 · hold

**전 문장 임시 검토용. 최종 안내 보류.**

- 역할 `benefit`: 가상 앱 쿠폰. 쿠폰 목록에서 발급 안내를 확인할 수 있습니다.

- 역할 `conditions`: 대상은 가상 앱 회원이고, 이용 채널은 가상 앱 주문입니다. 기간은 2026년 10월 1일부터 2026년 10월 31일까지입니다. 최소 결제금액 미확인. 중복 사용 조건은 다음과 같습니다: 다른 쿠폰 중복 불가. 표시 가격은 세금 포함입니다.

- 역할 `step`: 1단계. 앱의 쿠폰 목록을 엽니다.

- 역할 `step`: 2단계. 해당 쿠폰의 상세 조건을 확인합니다.

- 역할 `verification`: 발급과 결제 완료는 해당 화면으로 별도 확인해야 합니다.

- 역할 `hold`: 미확인 또는 불일치가 남아 있습니다. 혜택의 최종 안내는 보류합니다.

## D · 여러 혜택 모음 · supported

- 역할 `theme`: 가상 혜택 세 가지입니다. 각 혜택은 따로 이용합니다.

- 역할 `item`: 가상 커피. 커피 한 잔 예상 3,000원입니다.

- 역할 `conditions`: 대상은 가상 앱 회원이고, 이용 채널은 가상 앱 주문입니다. 기간은 2026년 10월 1일부터 2026년 10월 31일까지입니다. 중복 사용 조건은 다음과 같습니다: 다른 쿠폰 중복 불가. 표시 가격은 세금 포함입니다.

- 역할 `item`: 가상 빵. 빵 한 개 예상 2,000원입니다.

- 역할 `conditions`: 대상은 가상 앱 회원이고, 이용 채널은 가상 앱 주문입니다. 기간은 2026년 10월 1일부터 2026년 10월 31일까지입니다. 중복 사용 조건은 다음과 같습니다: 다른 쿠폰 중복 불가. 표시 가격은 세금 포함입니다.

- 역할 `item`: 가상 음료. 음료 한 잔 예상 1,500원입니다.

- 역할 `conditions`: 대상은 가상 앱 회원이고, 이용 채널은 가상 앱 주문입니다. 기간은 2026년 10월 1일부터 2026년 10월 31일까지입니다. 중복 사용 조건은 다음과 같습니다: 다른 쿠폰 중복 불가. 표시 가격은 세금 포함입니다.

## E · 장바구니 조합 · supported

- 역할 `goal`: 상품과 쿠폰을 조합한 예상 결제금액을 계산합니다.

- 역할 `item`: 가상 상품 3개, 개당 10,000원입니다.

- 역할 `calculation`: 상품 합계 30,000원에서 즉시 쿠폰 5,000원을 빼면, 필수비용 포함 예상 결제는 25,000원입니다.

- 역할 `future_reward`: 추가 보상은 조건부 5,000원 상당의 포인트입니다. 다음 달 지급 조건을 충족해야 합니다. 지금 결제금액에서 빼지 않습니다.

- 역할 `conditions`: 대상은 가상 앱 회원이고, 이용 채널은 가상 앱 주문입니다. 기간은 2026년 10월 1일부터 2026년 10월 31일까지입니다. 최소 결제금액은 30,000원입니다. 혜택 상한은 5,000원입니다. 중복 사용 조건은 다음과 같습니다: 다른 쿠폰 중복 불가. 표시 가격은 세금 포함입니다.
