# Couponz 대본 검토 엔진 · 로컬 MVP 초안

공식 링크 또는 앱 화면녹화 요청을 받고, **제작 측이 검토한 주장·근거표**로 다섯 형식의 한국어 대본을 만드는 최소 엔진입니다. 현재 범위는 대본까지입니다. 효과·템포·자막 스타일·전환·CTA 시각표현은 사용자와 협의 대기이며 렌더 기능은 없습니다.

실제 링크 수집·OCR·ASR·앱 조작은 **미구현**입니다. `intake`는 요청만 기록합니다. 근거표와 형식 선택은 제작 측 작업이며 사용자에게 좌표·시간코드·JSON 작성을 요구하는 제품 흐름이 아닙니다. 이 CLI는 제작 담당자용입니다. 사실 검사는 입력의 출처 연결·조건·산식 정합성 검사이고, 공식 사이트 진위나 자유문장의 의미를 자동 검증하지 않습니다.

## 실행

Python 3.12 이상, 표준 라이브러리만 사용합니다. 설치와 API 키가 필요 없습니다.

```bash
python -m couponz intake --url https://example.invalid/offer --out /tmp/couponz-intake-v1.json
python -m couponz validate fixtures/B.json
python -m couponz draft fixtures/A.json --out /tmp/couponz-A-v1.json
python -m unittest discover -s tests -v
```

화면녹화·본인 음성·배경영상의 기존 로컬 경로는 `intake --screen-recording ... --voice ... --background ...`로 받을 수 있습니다. 업로드하거나 파일을 복사하지 않습니다. 자료는 저장소 밖 비공개 작업 경로에 두세요. 출력은 기존 파일을 덮어쓰지 않으므로 수정본에 새 경로를 사용합니다.

## 다섯 형식과 실제 synthetic 검사

| 입력 | 형식 | 검사 결과 |
|---|---|---|
| A | 단일 혜택 안내 | 가상 커피 3,000원과 조건 설명 |
| B | 가격·구성 비교 | 7,900+2,000=9,900, 세트도 9,900. 절약 없음 |
| C | 사용 절차 | 최소 결제 불명 → 대본은 임시 검토용, 최종 주장과 CTA 보류 |
| D | 여러 혜택 모음 | 독립 3항목. 임의 합계 없음 |
| E | 장바구니 조합 | 30,000−5,000=예상 결제 25,000. 미래 5,000포인트 별도 |

`fixtures/`는 전부 가상 자료이며 실제 행사 안내가 아닙니다. 대본 범위의 30개 단위·CLI 통합검사를 실제 실행해 통과했습니다. 기존 14개 수용 시험과 추가 15개 편집 QA는 전부 통과한 것으로 표시하지 않습니다. [검증 범위](docs/verification.md)와 [다섯 가상 대본](examples/scripts.md)을 확인하세요.

## 상태와 다음 단계

대본은 `script_review_only`이며 사용자 승인본이 아닙니다. `supported`는 제작 측이 검토했다고 기록한 주장표와 입력이 일치한다는 의미입니다. 최종 혜택 사실, 문장 정확성, 권리·개인정보는 제작 측 재검토가 필요합니다. synthetic 입력은 최종 실제 혜택 주장으로 승격하지 않습니다.

영상별·형식별·전체 피드백, 완전한 의존성 버전 고정과 복원, 실제 미디어 제작·QA는 다음 범위입니다. 현재는 새 파일 경로로 대본 수정본을 보존하는 수준이며 완전한 버전 관리 구현으로 세지 않습니다. 편집회의 후 구현 범위와 합격 기준을 확정합니다.

입력 계약: [사용법](docs/usage.md). 재사용 절차 초안: [Couponz 대본 스킬](.agents/skills/couponz-script/SKILL.md). 이 스킬은 저장소 초안이며 개인 계정에 설치·배포하지 않았습니다.
